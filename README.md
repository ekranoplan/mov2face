# mov2face
このツールは動画ファイルを入力としてその動画に登場する人物の顔の画像ファイルを出力するものである。以下の2つのプログラムから構成される。

## mov2img.py
このプログラムは、指定ディレクトリ内の動画ファイルを順に処理し、ffmpeg を用いて 1 秒ごとにフレーム画像を抽出する。

## img2face.py
このプログラムは、指定ディレクトリ内の画像から InsightFace を用いて顔を検出し、頭部全体が収まるよう領域を拡張して正方形に切り出す。ブレ量を評価して低品質画像を除外し、鮮明な顔のみを 1024×1024 にリサイズして保存する自動処理を行う。
